# Sales Data Analysis Project

## Overview

This project analyzes sales data from 2025 to identify sales performance, customer trends, product performance, and monthly sales patterns.

The project uses Python, SQL, and Power BI to clean, analyze, and visualize the data.

## Tools Used

- Python
- Pandas
- SQL
- SQLite
- Power BI
- Git & GitHub

## Key Results

- Total Sales: $787,616.12
- Total Orders: 1,000
- Total Units Sold: 4,532
- Average Order Value: $787.62

### Sales by Country

The Netherlands generated the highest sales at approximately $153,543, followed by Belgium and Austria.

### Sales by Product

Laptop was the best-performing product, generating approximately $337,698 in sales.

### Monthly Sales

October recorded the highest monthly sales at approximately $101,421.

## Purpose

The goal of this project was to demonstrate practical data analysis skills using Python, SQL, and Power BI, from raw data preparation through analysis and visualization.

* Data cleaning and preparation with Python and Pandas
* Exploratory data analysis
* SQL querying and data aggregation
* SQLite database management
* Data visualization with Power BI
* Dashboard development
* Business performance analysis
* Identifying sales trends and patterns
